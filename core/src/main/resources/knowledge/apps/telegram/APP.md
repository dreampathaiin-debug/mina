## What it is
Telegram is an instant-messaging app, package `org.telegram.messenger`. For the website see `telegram.org`.

## Interface
There is a Chats list, Contacts and a new-message entry; a new message picks a person from contacts or search. The page the app lands on after entering is not always Chats.

## Features
- **Read messages**: find the target in the chat list, enter, and scroll through history; each message has its sender and time. Groups, channels and contacts are different objects.
- **Send messages**: type in an existing conversation, or pick the recipient from Contacts or the new-message entry. After sending, a new bubble appears in the conversation. The contacts page can open a contact's profile.
