# Per-job fields in the job-list API

Within `zpData.jobList` returned by `/wapi/zpgeek/search/joblist.json`, each job has:

`jobName`, `salaryDesc` (salary in plain text, like "40-70K · 15 months"), `brandName`, `brandScaleName`, `brandStageName`, `brandIndustry`, `cityName`, `areaDistrict`, `businessDistrict`, `jobExperience`, `jobDegree`, `skills`, `welfareList`, `jobLabels`, `bossName`, `bossTitle`, `bossOnline`, `encryptJobId`, `securityId`, `lid`, `itemId` (its index in the list).
