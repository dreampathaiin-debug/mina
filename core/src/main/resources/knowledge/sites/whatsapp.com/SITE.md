## What it is
A global instant-messaging service. The web version `web.whatsapp.com` shares one account with the phone and desktop clients.

## Pages and URLs
Web entry `https://web.whatsapp.com/`. Before linking, the page shows a QR code, scanned by the phone's WhatsApp "Linked devices". After signing in, the left side holds the conversation list with search and a new-chat button; the chat window is on the right. The interface language follows the browser.

## Features
- **Reading**: the conversation list shows the title and the last message; open a conversation for the body and times, with the speaking member visible in groups.
- **Sending**: in an existing conversation, type in the bottom box and send; a new chat starts from New chat or by searching contacts.

## Known behaviour
Linked-device sign-in works by QR code, separate from phone-number verification. With newer linking methods, the phone need not stay online the whole time.
