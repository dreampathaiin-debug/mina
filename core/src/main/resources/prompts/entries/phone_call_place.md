Place a phone call directly through the system's CALL permission, without opening the dialer or tapping anything. The call really goes out at once, so only call this when the task says to call. If it returns permission_needed, tell the user to grant Mina the Phone permission (Mina Settings > Devices > Make calls opens the right page), then try again once. If call_failed, say so instead of retrying blind. To look up a number first, use phone_contacts_find.
