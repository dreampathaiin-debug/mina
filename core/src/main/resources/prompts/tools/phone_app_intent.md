Open an app's page directly through Android's standard intent, without operating its screens: whatsapp_chat opens WhatsApp's chat with that number, with the message typed in when given; map_directions starts turn-by-turn directions to the destination in Maps; play_media plays a YouTube video (a video URL or its 11-character video id) or opens the YouTube app's search results for those words; dial types the number on the dialer. The result says which app took it (handledBy). Two things always need a tap on screen afterwards: WhatsApp's send button, and the dialer's call button; the rest starts itself. If it returns not_supported, the app is missing or the target was wrong; fall back to opening the app and operating its screens. Prefer it over screen automation whenever the user asks for one of these (send a WhatsApp message to a number, navigate somewhere, play a song on YouTube): it is faster and far more reliable. One call per thing, like the other direct tools.
