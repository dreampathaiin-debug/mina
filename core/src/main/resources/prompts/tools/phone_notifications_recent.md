Read the phone's recent notifications, newest first, without opening any app: which app posted them, the title and text, and canReply=true when the notification carries a reply action. app narrows to one package, e.g. com.whatsapp. This is the way to check a message that arrived (WhatsApp, SMS, any app that posts notifications) without walking its screens. It only sees notifications posted since the phone's notification listener was granted, so a notification that arrived and was dismissed long ago may be gone. If it returns permission_needed, tell the user to open Mina's notification access (system settings, Special app access, Notification access, Mina), then try again once.
