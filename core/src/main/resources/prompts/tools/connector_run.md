Run one action on one of the user's connected apps through their Composio account, e.g. send an email (GMAIL_SEND_EMAIL), create an issue (GITHUB_CREATE_ISSUE), or post a message (SLACK_SEND_MESSAGE). Pass the exact tool slug from connector_actions, the app slug, and the arguments object matching the tool's parameter schema. This really performs the action on the user's account, so get the arguments right and only run actions the user asked for. If no account is connected for the app, tell the user to link it in Accounts > Connections.
